# DiamondLens PWA（オフライン対応）

試合記録・能力測定・データ分析のアプリです。一度開けば、電波がなくても使えます。
データはすべて端末のブラウザ内に保存され、外部へ送信されません。

## 中身
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（1ファイル完結。外部の通信なし） |
| `sw.js` | Service Worker。アプリをキャッシュしてオフライン起動を可能にする |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `icons/` | アイコン（192・512・マスカブル512・iOS用180・32） |
| `apple-touch-icon.png` / `favicon.ico` | iPhoneのホーム画面・ブラウザのタブ用アイコン（ルートにも置いています） |

## 公開のしかた（HTTPS で置く必要があります）
Service Worker は **HTTPS のページ**でだけ動きます（開発用の `localhost` は例外）。
フォルダの中身を、そのまま次のいずれかに置いてください。

- **Netlify**: https://app.netlify.com/drop にフォルダごとドラッグ＆ドロップ（無料・アカウントが必要）
- **GitHub Pages**: リポジトリにファイルを置き、Settings → Pages で公開
- **Cloudflare Pages**: フォルダをアップロードして公開

`index.html`、`sw.js`、`manifest.webmanifest`、`apple-touch-icon.png`、`favicon.ico`、`icons/` は**同じ階層**に置きます。
サブフォルダに置いても動きます（パスはすべて相対です）。

## 端末への入れかた
1. 公開したURLを、**電波のある場所で一度開く**（このとき自動でキャッシュされます）。
2. 次のどちらかでホーム画面に追加します。
   - iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
   - Android（Chrome）: メニュー → 「アプリをインストール」または「ホーム画面に追加」
3. 以降はホーム画面のアイコンから起動でき、機内モードでも使えます。
   チーム画面の「同期とアカウント」にある「オフライン動作」が「有効」になっていれば準備完了です。

## 試合の記録（スタメンと交代）
スタメンでは、打順ごとに選手と守備位置を選び、DH制（指名打者）の有無を選べます。試合中は「交代」から、代打・代走・守備交代・選手交代を記録できます。

## 守備の記録（相手の打球と失策）
相手の攻撃中の「インプレー」で、打球が転がった地点・打球の種類と強さ・処理した守備位置を記録できます。失策は、その守備位置の選手の記録になり、分析の「守備・走塁」で選手別・守備位置別に集計されます。

## 守備中のカウントと牽制
相手の攻撃中も、ボール・ストライク・アウトのカウントが動きます（4ボールで四球、3ストライクで三振）。牽制は、相手の攻撃中は投手の牽制、攻撃中は走者が受けた牽制として記録し、分析の「守備・走塁」で、投手別・走者別に集計します。

## 試合の記録（戻る・進む）
試合の記録の各入力画面に、「◀ 戻る」「進む ▶」があります。戻るは1つ前のプレーを入力した状態で開き、修正して保存し直せます。進むは、戻る前の状態にやり直します。

## 分析 → 失点
分析画面の「失点」から、失点サマリー・失点の場面（場面別・イニング別）・失点パターン（アウト数・失点の形・出塁方法）・最近の推移を見られます。各カードの✦で自動コメント、ⓘで説明を表示します。先攻・後攻での絞り込みもできます。アウトや走者の状態は、このバージョン以降に守備側で記録した試合から集計されます（以前の試合は総失点・イニング別などの一部のみ）。

## 分析の条件（対象・期間・試合の種類・大会）
分析画面の「≡ 条件」をタップすると、条件の画面が開きます。
- **対象**: チーム全体、または選手。
- **期間**: 直近5試合・今月・今年度・シーズン、または「期間指定」（春・夏・秋・前年度のボタン、または開始日と終了日）。前期間との比較は、直前の同じ日数と比べます。
- **試合の種類**: 紅白戦を除く（初期値）・すべての試合・公式戦・練習試合・紅白戦。
- **大会**: 試合に入力した大会名ごとに絞り込めます。大会名は、試合を始めるときの入力欄か、試合の詳細画面（一覧から試合を選ぶ）で入力・変更できます。以前の試合も、詳細画面で大会名を付ければ大会ごとに分析できます。

## 「その他の事象」画面（攻撃・守備）
試合の記録の「その他」を開くと、「打者」と「走者」の2つに分かれたカードが出ます。できない操作は、薄く表示され、理由が書かれます（例: 走者なし、2ストライク・一塁空き（2死）時）。
- **打者**: バントファウル（2ストライクでは三振）、死球、故意四球（申告敬遠）、振り逃げ、打撃妨害、落球（失策）、エンタイトル二塁打、犠打、犠飛、守備妨害（打者アウト）。攻撃では、スクイズも記録できます。守備では、四球・三振・ランダンプレーも押せます。
- **走者**: 盗塁、盗塁死、牽制（セーフ／アウトを選ぶ）、牽制死、牽制エラー、パスボール、暴投、ボーク、失策で進塁、守備妨害（走者アウト）、ボールデッド（+1塁／+2塁）。走者が複数いるときは、走者を選ぶ画面が出ます。
- **振り逃げ**: 2ストライクで一塁が空いているとき、または2アウトのときに押せます。三振をつけた直後なら「直前の三振を変更」になります。原因（暴投・捕逸・失策）を選びます。三振の記録は残り、打者は一塁へ進みます。守備では、暴投・捕逸はバッテリーの記録に、失策は捕手の失策になります。
- **落球（失策）**: 守備では、失策をした守備位置を選びます。ファウルフライの落球なので、打者の打席は続き、ストライクが1つ増えます（2ストライクのときは増えません）。
- **守備での打撃妨害**は、捕手の失策として記録し、その走者の得点は自責点に含めません。申告敬遠は四球に含めます。

## 攻撃の「その他」（申告敬遠・打撃妨害・パスボール・ワイルドピッチ・スクイズ）
自チームの攻撃中の「その他」から、次を記録できます。
- **申告敬遠**: 四球として記録し、四球に含めます（分析の打撃画面に回数を表示）。
- **打撃妨害**: 打者が一塁へ進みます。打席に数え、打数には数えません（出塁率の計算にも入れません）。
- **パスボール・ワイルドピッチ**: 塁上の走者を1つずつ進めます。三塁走者は生還します（打点は付きません）。分析の「得点・走塁」に回数と得点を表示します。
- **スクイズ**: 三塁に走者がいるときに記録します。成功は「犠打」「バント安打」、失敗は「走者が本塁でアウト」「併殺」「三振」「バントがアウト（走者は三塁のまま）」から選びます。成功率は「得点・走塁」に、全体と打者ごとに表示します。スクイズとして記録した打席だけが対象です。

## 分析 → 起用（守備位置・打順）
分析の下部の「起用（守備位置・打順）」で、次を見られます。
- 選手ごとの守備位置（出場試合数と、守備についたイニング数）。
- 守備位置ごとの打撃成績。
- 打順ごとの成績（打席・打率・出塁率・長打率・本塁打・打点など）と、選手ごとの打順の試合数。

このバージョン以降に記録した試合から集計されます。守備のイニング数は、終わったイニングを数えます（試合終了を確定したときの途中のイニングは、アウトや走者などの進行があれば数えます）。

## 守備のインプレー（2つの手順）
相手の攻撃中のインプレーは、①打球の結果・地点・処理した守備位置、②走者の結果と失策、の2つの手順です。失策は、打球を処理した選手とは別の選手（例: 三塁手が処理して一塁へ送球し、一塁手が落球 → 5-3E）にも付けられ、送球・落球・捕球の種類を選べます。1つのプレーに複数の失策も付けられます。

## 守備・投手成績・相手選手
失策の種類（送球・落球・捕球）、パスボール、ワイルドピッチ、ランダンプレー（挟殺）を記録でき、選手ごとに集計されます。相手打者（右打ち・左打ち・両打ち）と相手投手（右投げ・左投げ）を登録すると、対右・対左の成績が出ます。投手の防御率は、自責点×7÷投球回（7回換算）です。試合の画面の上部に、投手・打者・守備のランキングと対戦分析を表示します。

## 選手詳細（4つのタブ）
選手一覧で選手を選ぶと、概要・能力・試合・分析の4つのタブで見られます。測定の入力や登録情報の編集は、右上の「記録・編集」から行います。

## 能力レポート画像
選手詳細の概要タブの「📄 レポート画像を作成」から、打者用・投手用を選んで、2480×3508px の PNG を作れます。画像は端末内で作られ、外部へは送信されません。
保存できないときは、画像を長押しするか、「印刷／PDF」からPDFにしてください。

## 5-10-5の目標タイム
5-10-5（秒）の基準を、目標タイムの表に合わせました。男子の目標は小1→小6で 7.20・6.90・6.60・6.30・6.05・5.90、女子の目標は 7.40・7.10・6.80・6.50・6.25・6.10、上位選手の目標は 6.90・6.60・6.30・6.00・5.80・5.65 です。目標タイムで60点、点数の1段階（10点）は男子の「目標と上位選手の目標の差」（小1〜4は0.30秒、小5・6は0.25秒）で、男子の上位選手の目標は70点になります。女子は同じ1段階を使うので、上位選手の目標は男子より高い点になります。

## アイコンが表示されないとき
- すでにホーム画面に追加してあるときは、いったん削除してから、もう一度追加し直してください（古いアイコンが残ることがあります）。
- Claude の公開ページ（claude.ai のリンク）をホーム画面に追加しても、このアイコンにはなりません。zipを自分のHTTPSのサイトに置いて、そのURLを追加してください。
- ブラウザのタブのアイコンは、読み込み直し（キャッシュの削除）で更新されます。

## 更新のしかた
アプリを変更したら、`sw.js` の先頭近くにある `const VERSION = 'v18';` を `'v20'` のように変えて、
ファイルを置き直してください。端末は、電波のあるときに新しい版を取得し、**次の起動から**切り替わります。

## データについて（重要）
- データは、そのURL（ドメイン）のブラウザ内にだけ保存されます。**URLを変えると、以前のデータは見えなくなります。**
- ブラウザの「サイトデータの削除」や、端末の初期化で消えます。
- 定期的に、チーム画面の「バックアップ（項目ごと）」で書き出して、別の場所へ保存してください。
  項目は、全データ・選手記録・測定記録・試合記録（打席・投球・盗塁を含む）・グラウンド記録・対戦相手記録・シーズン・競技規則セット・チーム設定です。
  各項目の「書き出す」から、コピーまたは「ファイルに保存」ができ、「復元」で、その項目だけを戻せます。
  選手・測定・試合の記録は選手のIDで結びついているため、別々に復元すると対応がずれることがあります。まとめて戻すときは「全データ」を使ってください。
- 複数の端末で同時に使う機能（同期）はありません。

## 動作確認について
パソコン上の Chromium で、「初回読み込み → キャッシュ → 機内モード → 再読み込み・画面移動・データの保持」を確認しています。
iPhone の Safari や Android の実機では確認していません。公開後に、一度、機内モードで開いて確認してください。


## 試合形式（試合の規定）
新規試合の「試合形式」カードで、9回/7回/6回/時間制/その他、規定の回数、タイブレーク（開始の回・無死一二塁/一死満塁/その他）、コールド（回以降・点差を複数登録）、最長の回、時間制限（分）、DH を設定できます。「初期値に戻す」で選択中の規則セットの値に戻ります。
- タイブレーク開始の回に入ると、アウト数・走者を自動配置（自軍は打順の直前の打者から）
- コールド／サヨナラ／規定回数終了／最長の回／時間制限に達すると、記録画面に「試合終了へ／続ける」の提案を表示（自動では終了しません）
- 設定は試合ごとに保存され、試合の規定は試合情報にも表示されます。以前の試合は影響を受けません。


## 打順の提案（分析 → 打順の提案）
試合結果（打席・盗塁）と能力測定から、セイバーメトリクスの考え方で9人の打順を提案します。同じ選手は重複しません。
- 総合力は wOBA（四球・安打・長打の重み付け）。1番＝出塁率＋走力、2番＝最も総合力の高い選手、4番＝残りで長打率最上位、3・5番は総合力順、6〜9番は総合力の高い順。
- 打席が少ない選手は、チーム平均と能力測定値で補正（20〜30打席で実績と半々）。
- 欠席の選手は「出場できる選手」から外すと、残りで再計算します。
- 「確認した」を押した後、試合結果・能力測定の更新で提案が変わると、画面とホームに更新のお知らせを出します。
- スタメン設定画面の「分析の打順提案を反映」で、そのまま打順に入れられます（守備位置は元の選択を引き継ぎます）。

### 打順の提案の方式
画面上部で3方式を切り替えられます（選んだ方式は保存されます）。
- **USA方式**: 1番＝出塁率＋走力、2番＝最も総合力の高い選手、4番＝長打率最上位、3・5番は総合力順。
- **JPN方式**: 1番＝俊足・出塁、2番＝三振が少なく小技ができるつなぎ役、3番＝打率の高い巧打者、4・5番＝長距離打者（長打率・打点）。
- **KOR方式**: 1番＝出塁＋走力、2番＝出塁率が高く三振の少ない選手、3番＝最高の打者、4番＝長打の中軸、5番＝得点圏打率の高い勝負強い打者、9番＝出塁できる「第2の1番」。
JPN方式・KOR方式は、それぞれの野球で一般的とされる傾向を成績に当てはめた目安です（公式なルールではありません）。更新のお知らせは方式ごとに管理します。

## 打撃分析のカード構成（分析 → 打撃）
失点分析と同じく、カードごとに ✦（分析コメント）と ⓘ（見方の説明）を付けました。
- **打球カード**: 地点／方向／種類／引っ張りの4つの見方。地点では「すべて・ヒット・アウト・長打」の絞り込み、点とヒートマップの切り替え、＋／−での拡大縮小ができます。
- **打撃サマリー・打者ごとの判定・打球の強さ・走者状況別・OPSの推移**にもコメントと説明を追加しました。
- 打球の位置は、これから記録する打球は角度と距離で正確に保存します。以前の記録は方向と距離から位置を推定して表示します。
- 引っ張り／流しは、選手の打席（右・左・両）で判定します（両打ちは相手投手の左右で決めます）。

## 投手分析のカード構成（分析 → 投手）
失点・打撃分析と同じく、カードごとに ✦（分析コメント）と ⓘ（見方の説明）を付けました。
- **投球結果**: 「割合」（見逃し・空振り・ファウル・ボール・インプレー・死球のドーナツ図）と「カウント別」（0B〜3B × 0S〜2S の表。ストライク率／空振り率／ボール率／被打率を切り替え、色の濃さで高低を表示）。
- **制球と球の強さ**: 初球ストライク率・空振り率・ボール率を前期との差（pt）つきで表示。1打者あたりの球数も出します。
- **被打球**: 「地点」（点／ヒートマップ、すべて・被安打・アウト・長打の絞り込み、＋／−で拡大縮小）と「内訳」（方向と種類ごとの割合・被打率）。
- カウント別の被打率は、投球の記録順から打席を再現して推定します（打席の記録がない試合は含みません）。


## ホームの打球傾向
- ホームの「打球傾向」を、すべて／右打者／左打者／選手 の切り替え、ゾーン／点（直近40打球）表示、＋／－拡大、凡例の件数、方向の一言まとめに変更。
- ✦で分析コメント、ⓘで見方の説明。「分析 ›」から打撃分析へ移動できます。
- 以前の記録の打球位置は方向と距離からの推定です。
